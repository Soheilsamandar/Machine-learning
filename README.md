<h2>📖 About</h2>

<p>

This repository contains a collection of Machine Learning projects developed using Python and modern Data Science libraries.

The projects cover a wide range of real-world applications including regression, classification, prediction, recommendation systems, and business analytics.

Each project follows a complete Machine Learning workflow:

✔ Data Collection

✔ Data Cleaning

✔ Exploratory Data Analysis (EDA)

✔ Feature Engineering

✔ Model Training

✔ Model Evaluation

✔ Prediction

</p>

<h2>📂 Projects Included</h2>

<table>

<tr>
<th>Project</th>
<th>Description</th>
</tr>

<tr>
<td>🏠 House Price Prediction</td>
<td>Predict residential property prices using features such as area, location, number of rooms, and other housing characteristics.</td>
</tr>

<tr>
<td>🎓 Student Performance Prediction</td>
<td>Predict students' academic performance using educational, demographic, and behavioural information.</td>
</tr>

<tr>
<td>🚗 Car Price Prediction</td>
<td>Estimate used car prices based on mileage, engine specifications, fuel type, manufacturing year, and transmission.</td>
</tr>

<tr>
<td>💰 Employee Salary Prediction</td>
<td>Predict employee salaries using years of experience, education level, and professional information.</td>
</tr>

<tr>
<td>🛒 Store Sales Prediction</td>
<td>Forecast future store sales using historical business data and machine learning techniques.</td>
</tr>

<tr>
<td>🏦 Loan Approval Prediction</td>
<td>Predict whether a loan application is likely to be approved based on applicant information.</td>
</tr>

<tr>
<td>👥 Customer Churn Prediction</td>
<td>Identify customers who are likely to stop using a service based on behavioural and subscription data.</td>
</tr>

<tr>
<td>🩺 Diabetes Prediction</td>
<td>Predict diabetes risk using medical indicators such as glucose level, BMI, blood pressure, and age.</td>
</tr>

</tr>

</tr>
